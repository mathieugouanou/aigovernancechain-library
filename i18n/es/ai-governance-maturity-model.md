# Modelo de madurez de gobernanza de IA (ES-LATAM)
    
    Nota de estilo: sin rayas largas en este documento.
    
    Autoevaluación de cinco niveles, diseñada para el directorio.
    
    - Nivel 1: Ad hoc. Sin gobernanza formal. La IA se usa sin control.
    - Nivel 2: Incipiente. Primeras políticas, responsabilidades difusas.
    - Nivel 3: Definido. Marco repetible, roles asignados, controles documentados.
    - Nivel 4: Gestionado. Monitoreo activo, indicadores, revisiones regulares.
    - Nivel 5: Optimizado. Mejora continua, listo para certificación, gobernanza federada.
    
    Para cada nivel: criterios, evidencia esperada y siguiente paso para avanzar.
