# Modelo de maturidade de governança de IA (PT-BR)
    
    Nota de estilo: sem travessões neste documento.
    
    Autoavaliação de cinco níveis, projetada para o conselho.
    
    - Nível 1: Ad hoc. Sem governança formal. A IA e usada sem controle.
    - Nível 2: Incipiente. Primeiras políticas, responsabilidades difusas.
    - Nível 3: Definido. Estrutura repetível, papeis atribuidos, controles documentados.
    - Nível 4: Gerenciado. Monitoramento ativo, indicadores, revisoes regulares.
    - Nível 5: Otimizado. Melhoria continua, pronto para certificação, governança federada.
    
    Para cada nível: critérios, evidência esperada e próximo passo para avancar.
